Story Teller

AI-powered YouTube story channel automation — from story generation to upload, fully automated.

Port 5000 Flask · SQLite · ffmpeg · Python 3.11+ GitHub v{{ app_version }}
Studio Archive Production SEO Schedule YouTube FAQ

Overview

Story Teller automates the full YouTube story channel pipeline: AI writes the story → TTS voices it → AI generates scene images → captions are created → video is assembled → it uploads to YouTube. All 6 phases run end-to-end from a single browser dashboard.

Story Studio
Generate stories in 10 genres using Claude, OpenAI, or Gemini. Streams output live.
Voice Narration
Convert stories to MP3 narration using OpenAI TTS, Google TTS, or ElevenLabs.
Scene Images
Generate scene images per story paragraph using DALL-E 3, Stability AI, or Ideogram.
Video Assembly
Assemble narration + images + captions into MP4 using ffmpeg.
YouTube Upload
OAuth2 upload to YouTube with title, description, tags, thumbnail, and visibility.
SEO & Thumbnails
Claude generates optimized titles, descriptions, tags, and thumbnail text options.
Story Teller dashboard — full pipeline from generation to upload

Installation

Requirements

  • Python 3.11+, pip
  • ffmpeg installed and in PATH (for video assembly)
  • At least one AI API key: Anthropic, OpenAI, or Google Gemini
  • At least one TTS key: OpenAI, Google Cloud TTS, or ElevenLabs
  • Optional: Stability AI or Ideogram for scene images
  • Optional: Google Cloud OAuth2 credentials for YouTube upload

Steps

  1. git clone https://github.com/TechnoSage/Story_Teller.git
  2. python -m venv .venv && .venv\Scripts\activate
  3. pip install -r requirements.txt
  4. Install ffmpeg: ffmpeg.org → add to PATH
  5. python run.py
  6. Open http://127.0.0.1:5000 and add API keys in Settings

Quick Start

  1. Go to Settings and add your Anthropic (or OpenAI/Gemini) API key.
  2. Go to Story Studio, choose a genre and provider, and click Generate Story.
  3. The story streams in live. When complete, it's saved to the Archive automatically.
  4. Open Production to generate voice, images, captions, and assemble the video.
  5. Connect YouTube in YouTube Channel, then upload from Production.

Story Studio

The Story Studio is where you generate new stories. Choose a genre (Horror, Fantasy, Romance, Mystery, Sci-Fi, Thriller, Adventure, Comedy, True Crime, or Inspirational), an AI provider (Claude, OpenAI GPT-4o, or Google Gemini), and click Generate.

Story Studio — pick a genre, AI provider, and stream the story live

Stories are streamed to the browser in real time via Server-Sent Events (SSE). Once complete, they're saved to the Archive and linked to their production assets.

Archive

The Archive holds every generated story with its full production status (voice ✓, images ✓, video ✓, uploaded ✓). Click any story to open its production panel.

Archive — all stories with production status badges

Production

The Production panel takes a story through all remaining pipeline phases:

  1. Voice — choose TTS provider, generate MP3 narration
  2. Images — generate scene images (one per paragraph)
  3. Captions — generate SRT via Whisper or text estimation
  4. Video — assemble MP4 with ffmpeg (narration + images + captions)
  5. Upload — push to YouTube with OAuth2
Each phase can be run individually or in sequence. The pipeline remembers which phases are complete so you can resume after any failure.

SEO & Thumbnails

The SEO section uses Claude AI to generate optimized YouTube metadata for any archived story.

SEO & Thumbnails — AI-generated titles, descriptions, tags, and thumbnail options
  • 5 title options — click-optimized YouTube titles
  • Description — YouTube-formatted description with hook and call-to-action
  • 15 tags — searchable tags in a copyable list
  • 5 thumbnail options — each with headline, subtext, and visual style suggestions
SEO uses Claude Haiku via your own Anthropic API key — extremely low cost per generation.

Scheduler

The Scheduler runs the full pipeline automatically — story → voice → images → captions → video → upload — on a configurable schedule (manual trigger, daily, or weekly).

  • Create a job with a genre, AI provider, and TTS provider
  • Set schedule: manual, daily at a time, or weekly on a day/time
  • View run history: status, start time, duration, and output
  • The scheduler daemon runs in the background — start/stop from the Scheduler section

YouTube Channel

The YouTube Channel section connects to your YouTube channel via Google OAuth2 and lets you view channel info and recent uploads.

  • Enter your Google Cloud OAuth2 Client ID and Secret in Settings → YouTube API
  • Click Connect YouTube to authorize via the OAuth2 flow
  • Once connected, channel info and recent uploads appear in this section
  • Videos are uploaded directly from the Production panel
Your OAuth credentials are stored in instance/youtube_credentials.json (gitignored). Never commit this file.

Tests

The Tests section has 6 live test cards you can run individually or all at once:

  • Story — generates a short story and displays it inline
  • Voice — generates audio and embeds a player
  • Image — generates one scene image and displays it inline
  • Captions — generates SRT captions and shows the text
  • Video — assembles a test MP4 and embeds a video player
  • YouTube — verifies OAuth connection and shows channel info

Settings

Access Settings via the gear icon. All settings stored in instance/app_settings.json (gitignored).

  • Anthropic API Key — for Claude story generation and SEO
  • OpenAI API Key — for GPT-4o stories and TTS voice
  • Google AI API Key — for Gemini story generation
  • ElevenLabs API Key — for ElevenLabs TTS voice
  • Stability AI Key — for Stability AI scene images
  • Ideogram API Key — for Ideogram scene images
  • YouTube API Client ID / Secret — for YouTube OAuth2 upload
  • Stories Directory — where generated MP3/MP4/SRT files are saved

FAQ

You need at least one story AI provider (Anthropic, OpenAI, or Google) and at least one TTS provider (OpenAI TTS, Google Cloud TTS, or ElevenLabs). For images you need DALL-E 3 (OpenAI), Stability AI, or Ideogram. YouTube upload requires Google Cloud OAuth2 credentials.

By default, all generated files (MP3, PNG, SRT, MP4) are stored in the stories/ directory inside the project folder, organized by story ID. You can change this path in Settings → Stories Directory.

On Windows: download from ffmpeg.org or install via winget install ffmpeg. Make sure the bin/ folder is in your PATH. On Linux: sudo apt install ffmpeg. On Mac: brew install ffmpeg.

Create a Google Cloud project, enable the YouTube Data API v3, and create OAuth2 credentials (Desktop app type). Add the Client ID and Secret to Settings → YouTube API, then click Connect YouTube. A browser window opens for you to authorize. Credentials are saved locally in instance/youtube_credentials.json.

A heartbeat watchdog monitors browser activity. When all tabs close, the server shuts down after ~120 seconds. Keep at least one tab open if you have a long-running pipeline in progress (the scheduled daemon continues regardless).
